# 校区、私信与模拟交易验收

日期：2026-10-23。用户已明确选择课堂模拟支付。本功能没有真实扣款、收款、托管、分账或提现能力，所有余额无真实价值。

## 实际验证

完整测试 `run.ps1 test market --verbosity 1`：**31 项全部通过，36.895 秒**。原始输出：trading-full-test-output.txt；新增交易测试详细输出：trading-test-output.txt。系统检查和迁移一致性检查通过，0006—0008 已应用到当前数据库。

新增 8 项测试覆盖：

- 完整意愿、卖家接受、付款、确认收货流程；付款前不能结算，收货确认需勾选。
- 重复领取余额、重复付款、重复确认、重复退款不会重复记账；余额不足事务回滚。
- 模拟余额总和加订单托管款守恒，结算前卖家无收入；退款回到买家。
- 多买家可提出意愿，但同一商品仅可有一笔待付款或已付款交易，取消后释放。
- 第三人无法读取或发送他人私信、读取订单、执行交易动作；CSRF、空私信、超长私信和 XSS 转义。
- 订单价格和版本快照、防止陈旧意愿被接受；进行中交易期间卖家不能修改、下架或手工标记已售出。
- 三个校区的显示、无效校区拒绝、订单地点独立快照；校区是用户自行填报，未验证。
- 后台管理员也不能通过常规表单直接修改或删除模拟订单与账务表。

重复点击测试为顺序重放，未做多进程压力测试。并发保护使用事务、条件更新、按商品和会话的活动订单唯一约束；本地 SQLite 不适用于高并发生产交易服务。

## 操作与限制

个人中心设置三个校区；既有用户未填写时提示尚未设置，不猜测其位置。校区在商品详情公开，即使用户未公开个人主页；设置表单已说明。面交具体地点只在双方私信和订单中显示。

私信是持久化留言方式，手动刷新，不是即时 WebSocket 聊天。付款前双方可取消；付款后由卖家同意并执行模拟退款，未实现争议仲裁、自动超时、退货物流、真实支付对账等功能。未发生真实资金交易。

订单、余额、流水和事件在管理后台只读；参与人和商品采用保护性外键，以免正常删除操作破坏交易记录。后台新增个人资料管理，可查看校区。普通第三人无法通过网页访问他人订单或私信；数据库维护者天然可访问底层数据。

再次演示可由卖家将演示商品重新上架，再经管理员审核后发起新订单；旧记录和余额不会被初始化命令覆盖。
