# 完整上线版 v2 验收记录

日期：2026-11-06。部署目标：整个项目完整部署到 Vercel，前后端均上线，关闭本机后可直接访问，刷新和换设备后数据保留，不要求先运行本机 app.py。

## 改动

- 保留完整 Django 服务端渲染：模板、CSS、Django WSGI 后端、管理后台和模型接口在同一个 Vercel 项目。
- 账号、商品、图片、收藏、私信、模拟订单、管理日志统一持久化在云端 PostgreSQL，生产禁止退回 SQLite。
- 新增 `/api/health/`：实际连接数据库、检查业务表、检测 PostgreSQL 加密连接、图片存储、模板和真实模型；故障返回 503，无密钥或个人数据。只有完整云端条件满足时 cloud_ready 为 true，本机不会伪装通过。
- 新增 `/admin/deployment-check/`：仅超级管理员查看，可保存数据库标记，跨浏览器或重部署后核对；写入管理操作日志，不覆盖商品。保存操作要求 CSRF。
- Vercel build.py 明确拒绝本机和非 Production 构建，避免用本机 SQLite 构建结果充当云端发布。
- 新增 GitHub 手动公网检查 verify-live.yml；用户在网页填正式 Vercel 网址即可执行只读检查，报告明确保留人工业务及跨设备验收项目。
- 新增独立进程持久化检查 tools/check_persistence.py，只允许隔离本机数据库或 CI localhost PostgreSQL，不会自动写真实生产数据库。
- 版本标识：2026-11-06-fullstack-v2。新压缩包仅放在 交付包/完整上线版v2，旧包保留为历史，不应混用。
