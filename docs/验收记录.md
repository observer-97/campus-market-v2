## 训练与复现

实际运行 train_model，两算法各自训练、验证、最终测试，保存模型及完整评估。再次执行同一独立训练命令，evaluation.json 的 SHA-256 完全相同，记录见 train-reproducibility.json。没有在网页请求中训练。

清洗前后 97 条，当前语料没有缺失和完全重复；合并人工同组教材对，形成 96 组。训练 58、验证 21、测试 18。分组清单见 artifacts/split_manifest.csv；最终测试 14/18 正确，两算法 Accuracy 0.7778，Macro-F1 0.7328。选择使用验证指标和平局规则，非测试指标。

## 真实浏览器流程

使用本机内置浏览器访问 127.0.0.1:8001，实际完成：

1. 登录 demo_student。
2. 浏览市场，进入发布。
3. 输入 `【流程演示】羽毛球拍` 与商品描述，智能分类返回 `体育用品（MultinomialNB）`。
4. 点击采用建议类别，填写 38 元和明确的演示联系信息，发布成功，进入 `/products/9/`。
5. 点击收藏，按钮变为“已收藏 · 取消收藏”；我的收藏显示新商品。
6. 我的发布显示该商品，共 9 件（8 件初始化 + 1 件流程验收）。

## 环境问题及范围边界

初次 Python 3.14 虚拟环境 ensurepip 失败，安装依赖后 SciPy 原生扩展被 Windows 应用控制策略拒绝加载；这次尝试不算通过。切换现有 Python 3.12、项目内固定依赖后训练和上述检查成功。未修改安全策略。额外上传与数据清理测试最初受系统临时目录权限影响，已改用项目内临时目录后通过。

未测试真实手机硬件与局域网连通，未进行公网部署、负载/并发和生产安全审计。未实现可选相似商品推荐。演示数据非真实用户数据，18 条测试不能支持可靠泛化结论。临时验收服务器在交付前停止，按 README 命令启动。
