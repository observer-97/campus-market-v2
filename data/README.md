# 中文分类示例数据

`examples.csv` 为本次开发由 AI 辅助逐条编写、人工可审阅的 97 条课程示例；未使用真实用户交易、网络抓取或公开数据集。没有用商品模板批量替换词语凑数量。每类覆盖不同商品、用途和表达。原 Android 资料提供四分类名称和业务流程，没有提供可复用的标注语料。

| 字段 | 含义 |
|---|---|
| id | 全局唯一文本 ID |
| title | 商品标题，非空 |
| description | 商品描述，非空 |
| category | study / digital / sports / daily |
| source | 来源、采集或编写说明，非空 |
| group_id | 同商品、同模板、改写样本共用 ID，非空；独立样本用独立 ID |

类别对应学习、电子、体育、生活用品，沿用 `源代码/MyApplication3/app/src/main/res/values/arrays.xml`。科学计算器归学习；阅读器、电子词典归电子；球鞋和运动腰包归体育；普通帆布包、吹风机和台灯归生活。边界由课堂业务定义，真实数据应制定更完整的标注规范。

`study-001` 与 `study-025` 为同类高数教材不同描述，明确共用 `study-01` 分组。分组不等于去掉所有同类商品：近重复识别针对描述高度重合或同一模板，不能把“都是书”视为文本重复。

训练命令会去掉缺失字段和规范化后完全重复文本；重复文本类别冲突、重复 ID、未知类别会停止训练。训练前用人工 group_id、字符二元组 Jaccard ≥ 0.65 或 SequenceMatcher 比例 ≥ 0.82 建立连通分组。该启发式不能保证识别语义改写，补充数据必须人工审查同模板和同来源系列并填写 group_id。当前逐对检测适合小数据集，规模扩大需改进算法。

替换步骤：复制 CSV 表头，收集已获许可且去除隐私的文本，双人复核类别；给同模板及近重复样本相同 group_id；每类至少 5 个独立组，尽量远多于此；执行 `train_model --data 路径`，审查清洗报告与划分清单，重启网页服务。不要将联系方式写入训练文本。预留独立真实测试集后，应冻结测试集，不能根据测试指标反复修改模型。

`tools/create_examples.py` 只重建本演示 CSV，不操作数据库；不会在启动和网页请求中运行。
